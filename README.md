# TM Nxera site assets

Built CSS and JavaScript for the TM Nxera website (tmnxera.com), served through jsDelivr.
Do not edit these files by hand: they are generated from the tmnxera-website repo by `build-ozem.py`, `minify.py` and `release.py`.
Each commit is a release; the live page pins one commit, so rolling back means pointing the page at an older commit.
